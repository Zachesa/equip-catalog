# Equip Catalog — Минимальный каталог поставщиков и оборудования

> Демонстрационный проект на **чистом PHP 8.4** без фреймворков и CMS.  
> Полностью соответствует требованиям: ООП, DRY, типизация, enum, `match`, безопасность.

---

## 🎯 Цель
Показать умение проектировать **масштабируемую, безопасную и поддерживаемую архитектуру** на чистом PHP, без «типовых» решений.

---

## ✨ Особенности

- ✅ **Чистый PHP 8.4** (без Laravel, Symfony, WordPress)
- ✅ **ООП + DRY**: репозитории, сервисы, traits (`Sanitizable`, `Validatable`)
- ✅ **Современные фичи**: `readonly class`, `enum`, `match`, строгая типизация
- ✅ **Безопасность**: CSRF, XSS, SQL-инъекции, валидация
- ✅ **Архитектура**: разделение на модели, репозитории, контроллеры
- ✅ **GD-поддержка**: обработка изображений (логотипы, фото оборудования)
- ✅ **Docker**: полная изоляция (PHP 8.4 + Nginx + MySQL)

---

## 🛠️ Технологии

- **Язык**: PHP 8.4 (FPM)
- **Веб-сервер**: Nginx
- **База данных**: MySQL 8.0
- **Контейнеризация**: Docker + Docker Compose
- **Утилиты**: Composer, Supervisor

---

## 🚀 Запуск (локально)

1. Клонируйте репозиторий:
   ```bash
   git clone <ваш-репозиторий>
   cd equip-catalog

2. Соберите и запустите:
    docker-compose up -d --build

3. Примените миграцию (один раз):
    Get-Content database/schema.sql | docker-compose exec -T db mysql -u equip_user -pequip_pass123 equip_catalog

Откройте в браузере:
→ http://localhost:8080

🧪 Функционал
Просмотр списка оборудования и поставщиков
Добавление, редактирование, удаление записей
Фильтрация по статусу (active, discontinued, archived)
Валидация форм и защита от CSRF/XSS
Поддержка изображений (через GD)

Этот проект — не «просто CRUD», а демонстрация инженерного подхода:

Код написан с нуля, без генераторов;
Архитектура позволяет легко добавлять новые сущности;
Все зависимости — только те, что действительно нужны;
Готов к расширению: API, авторизация, экспорт, изображения.
